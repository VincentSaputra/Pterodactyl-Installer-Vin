# Pterodactyl Auto Installer

Script otomatis instalasi Pterodactyl Panel & Wings untuk Ubuntu.

## Usage

```bash
# Install Panel
curl -fsSL https://raw.githubusercontent.com/USERNAME/REPO/main/install.sh | bash -s panel panel.example.com

# Install Wings
curl -fsSL https://raw.githubusercontent.com/USERNAME/REPO/main/install.sh | bash -s wings https://panel.example.com
```

## Local Usage

```bash
chmod +x install.sh
./install.sh panel panel.example.com
./install.sh wings https://panel.example.com
```
